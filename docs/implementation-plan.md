# CableDriven-UAV-BoundarySystem 计划文档

本文档将系统化列出无人机缆控边界系统的交付目标、工程拆解、接口与验证路径，指导后续硬件搭建与软件开发。

## 1. 设计目标

- **核心功能**：四套带编码器卷扬 + 恒张力控制 + 可编程软/硬限位 + 虚拟墙越界保护。
- **部署方式**：全部使用现成模块（电机/驱动/开发板/HX711/杜邦线），不自制 PCB。
- **接口统一**：下位机经 USB/串口与 PC/RPi 上位机通讯，支持实时状态回传与命令更新。
- **扩展性**：后续可替换为其他数量的卷扬或更高层算法而无需重构底层硬件。

## 2. 约束与假设

- 工作空间约 2 m 边长，卷筒有效半径 30–50 mm，单根绳长不超过 2.5 m。
- 无人机质量较轻（< 3 kg），单根绳正常张力 1–5 N，虚拟墙峰值张力 < 40 N。
- 供电统一采用 12 V 或 24 V 直流电源，电源功率需覆盖四台电机同时收绳的峰值电流。
- 传感器信号与驱动控制均与 MCU 共地，布线采用杜邦线/端子，必要处加扎带减震。

## 3. 模块选型建议

| 模块 | 建议件 | 备注 |
| --- | --- | --- |
| 电机+编码器 | 12 V/24 V 编码器直流减速电机（37 mm 外径） | 带 AB 相霍尔；减速比 1:30~1:100；输出力矩足够克服最大张力 |
| 电机驱动 | BTS7960（43 A H 桥）或 L298N | 每根绳一块；若选闭环步进，则使用 TB6600 或自带驱动 |
| 张力传感器 | 0–10 kg 微型拉力传感器 + HX711 | HX711 SPI-like 接口，单片 MCU 需读取 4 组 |
| 控制板 | ESP32 DevKitC 或 STM32F407VET6 最小系统板 | 需 >= 8 个编码器输入通道；若资源不足可增设编码器扩展板 |
| 上位机 | PC / 树莓派 4B | 运行 Python/ROS 节点，负责定位与虚拟墙逻辑 |

## 5. 固件开发路线

1. **驱动抽象层**
   - 编码器：使用中断或高速计数外设，定期换算成绳长（`length = 2πR * count / counts_per_rev`）。
   - 张力：HX711 驱动库，提供零点/跨度校准函数，输出牛顿值。
   - 电机：封装 `set_motor(i, command)`，输入为正负归一化速度，内部映射到 PWM 和方向引脚。

2. **控制循环**
   - 采样频率 200 Hz 左右；依次执行传感器读取、限位逻辑、恒张力 PI、输出更新。
   - 可编程限位 `L_max[i]` 和缓冲带 `ΔL[i]`，通过串口命令修改并存储在非易失性内存。

3. **通讯协议**
   - 采用简易 JSON 或二进制帧：`{id: i, T: value, Lmax: value, mode: ...}`。
   - 周期性上报：`{timestamp, L_i, T_i, motor_state}`，便于上位机定位与监控。

4. **保护机制**
   - 电流/温度异常自动停机。
   - 编码器或张力数据超范围时进入安全模式（减速 + 提示上位机）。

## 6. 上位机软件路线

1. **通讯层**：基于 pyserial/ROS 串口节点，处理命令下发与状态解析。
2. **定位算法**：
   - 输入：4 个锚点坐标 `M_i`（安装时测量）与绳长 `L_i`。
   - 算法：非线性最小二乘（如 `scipy.optimize.least_squares`）或卡尔曼滤波融合。
3. **虚拟墙控制**：
   - 定义工作空间（长方体/自定义多面体）。
   - 进入缓冲区时生成虚拟墙力 `F_wall`（与越界距离相关）。
   - 求解张力增量 `ΔT`（非负最小二乘），叠加到基础张力 `T_base`。
4. **调试工具**：
   - 实时可视化无人机坐标、张力、限位状态。
   - 提供指令接口：修改 `T_base`、`L_max`、控制模式。
