# CableDriven-UAV-BoundarySystem

## 项目简介

本仓库聚焦于构建一套 **「带编码器电动卷扬 + 恒张力 + 可编程限位 + 虚拟墙」** 的多绳缆控无人机边界系统。整体目标是：

> 4 套电动卷扬（电机+卷筒+编码器+张力测量） → 单板控制层（绳长/张力闭环） → 上位机（空间位置解算 + 虚拟墙逻辑） → 反馈张力/长度目标给卷扬。

该仓库将沉淀从硬件 BOM 选型、控制策略到软件实现计划的完整资料，方便后续快速落地与迭代。

## 系统架构

| 层级 | 核心功能 | 关键模块 |
| --- | --- | --- |
| 机械层 | 卷筒+绳子+电机+编码器，拉力传感器（可选） | 编码器直流减速电机 12V/24V、37mm 霍尔编码器减速电机、闭环步进一体机、凯夫拉/涤纶绳、微型拉力传感器、HX711 |
| 低层控制 | 读绳长/张力，输出电机 PWM/方向，恒张力闭环，可编程限位 | ESP32/STM32 开发板，BTS7960/L298N 驱动，HX711 模块，限位开关 |
| 上位机 | 采集 4 根绳长，解算 3D 坐标，虚拟墙逻辑，生成张力/长度指令 | PC/树莓派 + Python/ROS，串口通讯 |

## 硬件方案摘要

1. **卷扬机构**：卷筒有效半径 30–50 mm（推荐 40 mm），2 m 行程约 8 圈。选用低伸长率凯夫拉或高强涤纶绳（1.5–2 mm）。
2. **电机+编码器**：优先选择带编码器直流减速电机（12/24 V，1:30~1:100 减速，双通道 AB 相），驱动采用 BTS7960 或 L298N。也可选闭环步进 iHSV/iHSS（Step/Dir 控制）。
3. **张力测量**：每根绳接 0–10 kg 微型拉力传感器 + HX711 放大模块。若前期不装传感器，可由电流估算张力，但恒张力精度下降。
4. **控制核心**：ESP32 或 STM32F407 开发板汇集 4 组编码器、4 组驱动 PWM/DIR、4 个 HX711 和限位开关。上位机为 PC/RPi，经 USB/串口交互。

## 控制策略概述

### 低层（卷扬）：恒张力 + 限位

- 每根绳实时读绳长 $`L_i`$ 和张力 $`T_i`$。
- 目标张力 $`T_{i,target}`$ 由上位机决定，正常保持小常数（如 2 N）。
- PI 控制律：$`u_i = K_P e_T + K_I \int e_T dt`$；输出映射到 PWM 和方向。
- 软件限位：
  - $`L_i < L_{max}-\Delta L`$：自由恒张力。
  - $`L_{max}-\Delta L \le L_i \le L_{max}`$：逐渐提高张力，形成软缓冲。
  - $`L_i > L_{max}`$：禁止放绳，只允许停机/收绳。

### 上位机：定位 + 虚拟墙

1. **定位**：根据卷扬锚点 $`M_i`$ 和测得绳长 $`L_i`$，解非线性方程组 $`|P-M_i| = L_i`$ 获取无人机位置 $`P`$。使用上一帧结果作为迭代初值，数值求解（最小二乘/牛顿法）。
2. **虚拟墙逻辑**：定义允许区域（长方体/多面体），设置软边界（例如 20 cm 缓冲）。当靠近或越界时生成虚拟墙力 $`\mathbf{F}_{wall}`$。
3. **张力分配**：求解 $`\Delta T_i`$ 使 $`\sum \Delta T_i \mathbf{u}_i \approx \mathbf{F}_{wall}`$ 且 $`\Delta T_i \ge 0`$，得到新的 $`T_{i,target} = T_{base} + \Delta T_i`$，通过串口下发给低层。

## 实施计划（第一阶段）

1. **BOM & 采购**
   - 列出 4 套卷扬+传感器的具体型号，确认供电（12 V/24 V）与电流余量。
   - 准备 ESP32/STM32 开发板、HX711、驱动模块、USB-TTL、杜邦线/接线端子。
2. **机械装调**
   - 加工/打印卷筒与支架，安装拉力传感器固定结构。
   - 校准卷筒有效半径，记录为编码器→绳长换算系数。
3. **低层固件开发**
   - 构建传感器/驱动抽象：编码器中断采样、HX711 读取、PWM 输出。
   - 实现恒张力 PI、软/硬限位、串口指令解析（目标张力、限位设置、状态反馈）。
4. **上位机原型**
   - Python/ROS 节点：串口通讯、绳长采集、3D 位置解算、虚拟墙力生成、张力分配。
   - 提供调试界面或命令行监控张力、位置、状态。
5. **系统联调**
   - 单卷扬闭环验证（张力/限位）。
   - 4 套联动 + 上位机虚拟墙验证，逐步扩大工作空间。
